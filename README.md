# Breast Cancer Detection using Machine Learning

This project predicts breast cancer using machine learning.

Dataset: Kaggle Breast Cancer Dataset

Technologies:
Python
Scikit-learn
Pandas
Matplotlib

Model Accuracy: 97% by QCCNN

## Dataset

Breast Cancer Wisconsin (Diagnostic) Dataset from Kaggle:

https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data

This dataset is used to predict whether breast cancer is benign or malignant using machine learning.
